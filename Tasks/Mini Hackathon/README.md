# React To-Do List

A simple and responsive To-Do List application built using React.js. This project helps users manage their daily tasks by adding, completing, and deleting tasks efficiently.

## 🚀 Features

* Add new tasks
* Mark tasks as completed
* Delete tasks
* Real-time UI updates using React State
* Clean and responsive design
* User-friendly interface

## 🛠️ Technologies Used

* React.js
* JavaScript (ES6+)
* HTML5
* CSS3
* Vite

## ⚙️ Installation

1. Clone the repository

```bash
git clone <repository-url>
```

2. Navigate to the project directory

```bash
cd react-todo-list
```

3. Install dependencies

```bash
npm install
```

4. Start the development server

```bash
npm run dev
```
